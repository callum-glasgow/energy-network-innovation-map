Energy network innovation map — local snapshot

When published on GitHub, download energy-network-map.zip from the
repository Releases page. The ZIP is distributed through GitHub, not the map.
Extract the whole ZIP first. Requires Python 3, with no extra packages.
macOS/Linux: run python3 serve.py from this folder, or Start map.command.
Windows: run py -3 serve.py, or Start map.bat.
Open http://127.0.0.1:8766/ if the browser does not open automatically.
Use --port 9000 if the port is occupied. Press Ctrl+C to stop.

Project sizes default to recorded investment amounts; colours identify
similarity groups. Diamonds show Live, circles Complete, squares other or
unrecorded source statuses. Equal investment keeps equal area across shapes.
Zoom out stops at the complete visible-project overview. Select Map to draw
projects; use Full screen map to expand it. Escape or Exit full screen map
returns to the normal page. Fit visible projects resets the map framing.

The complete map, filters, comparisons and original evidence work without
internet access. External ENA source links require internet access.
Open through the supplied local server, not by double-clicking index.html:
browsers restrict fetching snapshot files from file:// URLs.
No API key, accounts, backend services or model calls are required.
The separate evidence-search/report application is not part of this package.

This is a dated public-data snapshot. Counts and coverage are shown in the app.
Generated similarity groups support investigation, not proof of novelty,
duplication, benefits, actual expenditure or delivery performance.
Budget totals sum source entries/phases and may overlap across programmes.
